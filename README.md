# StudyMate AI

一个面向学习场景的 AI 学习资料助手网页原型。

当前是 **第 1 周原型（v0.1）**：聊天、输入、上传界面和本地模拟回复已经可用，**尚未接入真实 AI API**，上传的资料也不会被读取或发送。

- 最后更新：2026-11-04
- 运行方式：本地静态网页
- 技术栈：HTML5 / CSS3 / 原生 JavaScript

---

## 项目简介

StudyMate AI 的目标是帮助学习者完成三件事：

1. 上传一份学习资料
2. 让 AI 总结重点并依据资料回答问题
3. 根据资料生成复习题

第 1 周先完成“能看、能点、能对话”的网页原型，验证页面结构和交互流程。真实 AI、文件解析和历史记录放在后续阶段。

## 功能范围

### 已实现

- 顶部导航：品牌名、AI 学习助手标识、版本号
- 聊天区：欢迎页、用户消息、AI 消息、时间与“演示回复”标识
- 输入区：
  - 空内容时发送按钮禁用
  - `Enter` 发送
  - `Shift + Enter` 换行
  - 中文输入法选词时按 `Enter` 不会误发送
  - 输入框高度随内容自动调整
- 模拟回复：
  - 发送后显示“正在输入…”三个点
  - 约 0.7–1.2 秒后返回本地模拟回复
  - 根据“总结 / 复习 / 解释 / 你好”等关键词返回不同文案
- 示例问题：点击后填入输入框并获得焦点
- 资料上传区（仅界面）：
  - 点击选择文件或拖拽文件
  - 显示文件名、大小、类型
  - 文件计数
  - 重复文件提示并跳过
  - 不支持格式或超过 10MB 的文件提示并跳过
  - 移除已添加的文件
- 桌面端双栏布局，窄屏自动切换为单栏
- 玻璃质感卡片、渐变按钮、悬停与入场动效

### 暂未实现

- 调用真实 AI 模型
- 读取 TXT / Markdown / PDF 的内容
- 真正的资料总结与问答
- 自动生成复习题
- 保存和查看历史对话
- “总结资料重点”按钮（当前保持禁用）
- 完整的深色模式
- 自动化测试与线上部署

## 目录结构

```text
studymate-ai/
├── index.html        # 页面结构：导航、聊天区、输入区、上传区
├── css/
│   └── style.css     # 设计变量、布局、消息气泡、响应式、动效
├── js/
│   └── app.js        # 发送逻辑、模拟回复、输入状态、上传区演示
└── README.md         # 本文件
```

数据流：

```text
用户输入 / 点击示例问题
        ↓
app.js 监听输入与提交事件
        ↓
追加用户消息 → 显示“正在输入…”
        ↓
setTimeout 等待 0.7–1.2 秒
        ↓
buildMockReply() 生成本地模拟回复
        ↓
追加 AI 消息 → 恢复发送按钮
```

## 运行方式

### 环境要求

- Windows 10 / 11
- Python 3.10 或更高版本（本项目开发时使用 Python 3.12）
- Chrome / Edge 等现代浏览器

检查 Python 是否可用：

```powershell
python --version
```

### 启动本地服务器

在 Windows PowerShell 中执行：

```powershell
cd "$env:USERPROFILE\Desktop\studymate-ai"
python -m http.server 8000
```

浏览器打开：

```text
http://localhost:8000
```

停止服务器：回到 PowerShell 按 `Ctrl + C`。

### 备用方式

也可以直接双击 `index.html`。当前版本没有网络请求，因此 `file://` 方式也能运行。  
使用本地服务器更接近后续开发方式，推荐优先使用。

### 端口被占用

如果 8000 端口已被占用，换一个端口：

```powershell
python -m http.server 5500
```

然后访问 `http://localhost:5500`。

## 使用说明

1. 在底部输入框输入问题。
2. 按 `Enter` 或点击“发送”。
3. 观察用户消息、“正在输入…”和 AI 模拟回复。
4. 点击欢迎页的示例问题，可以把问题填入输入框。
5. 在右侧上传 TXT、Markdown 或 PDF 文件，只会更新界面列表，不会读取或上传文件内容。
6. 刷新页面会清空所有消息和文件列表，恢复初始状态。

## 已知限制

- **AI 回复是假的**：`js/app.js` 中的 `buildMockReply()` 只做关键词匹配，不调用任何模型。
- **上传不会真正发生**：只读取文件名、大小和扩展名，不读取文件内容，也不发送到服务器。
- **“总结资料重点”不可用**：按钮保持禁用，避免让人误以为资料已经被解析。
- **没有持久化**：刷新页面后消息和文件列表全部丢失。
- **深色模式不完整**：当前只覆盖了背景、卡片、输入框等部分区域，欢迎文字、示例问题、文件条目等仍可能出现浅色配色。
- **没有自动化测试**：当前使用手工测试清单；开发过程中曾用临时浏览器脚本检查核心流程，但测试文件未纳入项目。
- **未部署**：只能在本地运行。

## 安全说明

当前版本：

- 没有任何 API Key
- 没有 `fetch` 或其他网络请求
- 没有上传或读取用户文件
- 没有收集个人信息

后续接入 AI API 时必须遵守：

1. API Key 只放在后端 `.env` 文件中
2. 不把 Key 写入前端代码
3. 不把 `.env` 提交到 Git
4. 前端只请求自己的后端接口
